Security Audit

April 4, 2026
✓ Patched - 10 Findings Fixed
  • CRIT Rate limiting on all auth endpoints (Redis, IP-scoped)
  • CRIT Tenant isolation on all update/delete queries
  • CRIT Middleware matcher narrowed (only /api/auth excluded)
  • CRIT Password reset tokens: crypto.randomBytes + SHA-256
  • CRIT MFA secrets encrypted at rest (AES-256-GCM)
  • HIGH Mass assignment prevention via explicit destructuring
  • HIGH Pagination clamped 1-100 on all queries
  • HIGH Session invalidation after password change
  • LOW Password validation consistency (Zod schema)
  • LOW Removed unused jsonwebtoken dependency

  • HIGH RBAC enforcement - needs permission seeding + role UI
  • HIGH Sequential number race condition - needs DB sequence

1

Add API Keys to Coolify (Quick Win)

Configure VAPID, reCAPTCHA, Razorpay/Stripe, Google/Outlook OAuth, WhatsApp, and social media API keys. This activates 8 integrations already built into the codebase with zero code changes.

2

Frontend Website (Public-Facing)

Build a marketing website with product landing pages, feature showcase, pricing tiers, customer testimonials, and a signup/onboarding flow. Can be built as a separate Next.js site or as a public route group within the existing app.

3

Flutter Mobile Apps (Android + iOS)

Cross-platform mobile app using Flutter/Dart. Core modules: attendance (GPS + biometric), field service work orders, barcode/QR scanning, push notifications, and a mobile dashboard. Shared codebase targets both Google Play and App Store. This unlocks 4 of the 13 remaining features.

4

REST API Layer + Webhooks

Build a documented REST API (OpenAPI/Swagger) for external integrations, third-party app connections, and mobile app backend. Add webhook support for real-time event notifications to external systems.

5

Bank Reconciliation + Third-Party Connectors

OFX/CSV bank statement import for automated reconciliation (FIN-A-007). Zomato/Swiggy POS integration pending business account setup. Website visitor tracking pixel and social listening API integration.

6

Hardware SDK Integrations

Biometric attendance device SDK (fingerprint/face recognition), barcode/QR scanner hardware support, GPS vehicle tracking integration. These 4 features depend on specific hardware vendor partnerships.
