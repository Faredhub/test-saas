Quick Start

Get authenticated and make your first API call in under a minute.

1

Authenticate

POST your credentials to get a JWT token valid for 30 days.

curl -X POST https://trp.tpdemo.in/api/v1/auth \ -H "Content-Type: application/json" \ -d '{"email": "rajesh.kumar@example.com", "password": "SecurePass123"}'
2

Save the token

Extract data.token from the response. Store it securely on the device.

3

Make authenticated requests

Pass the token in the Authorization header for all other endpoints.

curl https://trp.tpdemo.in/api/v1/dashboard \ -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIs..."
Authentication All endpoints except POST /auth require a Bearer JWT token. Pass it as: Authorization: Bearer <token>. Tokens expire in 30 days and are invalidated when the user changes their password.

Error Codes

StatusMeaning
400Bad request (missing or invalid fields)
401Unauthorized (missing, invalid, or expired token)
403Forbidden (account inactive)
404Not found
409Conflict (e.g. duplicate clock-in)
423Account locked (too many failed login attempts)
429Rate limited
500Internal server error

Response envelope: Success responses return {"success": true, "data": { ... }}. Errors return {"error": "message"}. Paginated endpoints return data.data (array), data.total, data.page, data.limit, data.totalPages.

Auth

POST /auth Public Log in and get JWT token ▶

Authenticate with email and password. Returns a JWT token valid for 30 days and the user profile with linked employee record. Rate limited to 10 attempts per IP per minute. Account locks for 30 minutes after 5 failed attempts.

Request Body

FieldTypeRequiredDescription
emailstringYesUser's email address
passwordstringYesUser's password

Response (200)

{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": "clxyz123abc",
      "email": "rajesh.kumar@example.com",
      "name": "Rajesh Kumar",
      "tenantId": "tenant_001",
      "tenantSlug": "tixeltech",
      "roles": ["ADMIN", "HR_MANAGER"],
      "employee": {
        "id": "emp_001",
        "employeeId": "EMP-0042",
        "firstName": "Rajesh",
        "lastName": "Kumar",
        "designation": "Senior Engineer"
      }
    }
  }
}

cURL

curl -X POST https://trp.tpdemo.in/api/v1/auth \
  -H "Content-Type: application/json" \
  -d '{"email": "rajesh.kumar@example.com", "password": "SecurePass123"}'
